## 5. Start here — Phase 1: the character (what you can build without human painting)

You cannot paint textures by hand. You CAN script Blender headlessly to model clean, stylised, rigged,
vertex-coloured characters and export GLB. Do that, and be explicit about what is code-modelled.

1. Install Blender if missing: `winget install BlenderFoundation.Blender` (ask the user only if winget fails).
2. Create `tools/blender/` with Python (`bpy`) scripts, run as
   `blender --background --python tools/blender/build_character.py -- --out client/public/assets/models/characters`.
3. `build_character.py` produces, with a **shared humanoid skeleton** (bone names in `docs/ART_PRODUCTION_PLAN.md`
   Phase 1, incl. finger bones): `body_average.glb`, `body_slim.glb`, `body_broad.glb`; heads `face_01..03.glb`;
   hair `hair_01..04.glb`; outfit parts for `terracotta`, `blue`, `sage`, `mustard`, home and sleep wear.
   Quality bar: real head with eyes/nose/ears/mouth shapes, neck, shoulders, hands with fingers, feet in shoes,
   soft bevelled forms, flat painted-looking vertex colours + a baked AO/gradient so it reads like the references
   (rounded, warm, slightly exaggerated proportions; not capsules).
4. Animation clips (`idle`, `walk`, `jog`, `sit`) authored in Blender on that rig (bone-driven keyframes in
   Python), exported in the GLB. Keep the procedural fallback for all other actions.
5. Write `<id>.source.md` for every file (author: "generated by tools/blender scripts", tools, licence: project-owned).
6. `node tools/asset-index.mjs` must pass; commit GLBs (each under 12 MB; target < 2 MB) with the scripts.
7. Hook up: add `ArtAssets` to `GameEngine`, make `PlayerAvatar` use `body_*`/`face_*`/`hair_*` GLBs when present
   (keep sockets: head, left/right hand, head camera mask, safety gear attach points, outfit colour params),
   falling back to the current procedural body if any piece is missing. Keep existing PlayerAvatar tests green
   (adapt only where behaviour intentionally changes) and add tests for the GLB path using a tiny generated GLB.
8. Ambient townsfolk: instance the GLB body/heads with per-instance colour; reuse the `limb` gait only if clips
   are not used. Keep draw calls ≤ the current two batches per LOD.
9. Capture `avatar-third-person.png`, a crowd shot, and a home first-person shot; compare to references; iterate
   until the character clearly beats the old capsule body. Commit + push after each sub-step.
